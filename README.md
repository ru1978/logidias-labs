**LOGIDIAS** ([www.logidias.com](https://www.logidias.com/)) is a 100% free, no-registration, bilingual (**Español / English**) interactive STEM educational platform featuring **40 browser-based 3D simulators and virtual laboratories**, **84 solved classroom lab worksheets**, and **30 science articles** alongside a weekly **arXiv Frontier Science Radar**.

Engineered by **Ruben Rodríguez** for students, educators, and STEM enthusiasts across **Primaria / K-5**, **ESO / Middle School**, **Bachillerato & EBAU / AP Physics-Chemistry-Biology**, and **College Undergraduate STEM**.

---

## Core Technology Stack
- **3D & Physics Engines:** Three.js, WebGL, HTML5 Canvas, 2D Navier-Stokes CFD, N-Body Orbital Mechanics, Client-Side Stockfish WebAssembly.
- **Pedagogical Layer:** Step-by-step solved problems (`/simuladores/`), real-time parameter calculators, shareable experiment presets (`?preset=1..3`), CSV telemetry export, and print-ready classroom worksheets.
- **Open Web & AI Search Standards (GEO/AEO):** Full JSON-LD `@graph` (`WebApplication`, `LearningResource`, `VideoGame`, `FAQPage`, `BreadcrumbList`), IndexNow instant indexing, `sitemap.xml` with `xhtml:link` hreflang pairs, RSS feeds, `llms.txt`, and `llms-full.txt`.
